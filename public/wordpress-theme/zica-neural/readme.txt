=== Zica Neural Publisher ===
Version: 1.0.0
Requires at least: 5.8
Requires PHP: 7.4
License: GPLv2 or later

Tema dinâmico complementar ao Zica Posts 3.10.0, com identidade Zica.ai Dark Graphite + Volt + Electric Cyan.

== Recursos ==
* Home dinâmica com hero neural e feed editorial.
* Single de artigo responsivo com estrutura semântica limpa.
* Archives responsivos.
* Custom Logo e menus principal/rodapé.
* Controles no Customizer para marca, título/texto do hero e cor de destaque.
* Compatibilidade visual com cards automáticos do Zica Posts.
* Desktop, tablet e mobile.
* prefers-reduced-motion para acessibilidade.
* theme.json com tokens de marca.

== Instalação ==
1. WordPress → Aparência → Temas → Adicionar novo → Enviar tema.
2. Envie o ZIP zica-neural-theme-1.0.0.zip.
3. Ative o tema.
4. Aparência → Personalizar → Zica Neural — Identidade.
5. Configure logo, menus, marca e hero.

O tema não é obrigatório para o funcionamento do plugin. O Zica Posts mantém APIs, descoberta, sitemap, IndexNow e arquivos LLM mesmo com outro tema ativo.
