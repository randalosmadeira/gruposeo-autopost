# Pacote de continuidade para Claude Code

1. Extraia o ZIP em um diretório novo.
2. Abra o Claude Code na raiz extraída.
3. Cole o conteúdo de `00_PROMPT_MESTRE.md`.
4. Permita primeiro apenas leitura, instalação de dependências e testes locais.
5. Configure credenciais somente no mecanismo seguro do ambiente; nunca no chat nem em arquivos versionados.

Este pacote é uma fotografia limpa do Git com instruções de continuidade. Ele não contém `.env`, tokens, senhas, `node_modules`, `dist` ou banco remoto.
