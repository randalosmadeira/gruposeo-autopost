# Schema da homepage + correções do Observatório — contrato (12/11/2026)

Branch `nexus-fusion-2026-11-12`. Nada é implantado por quem implementa; o coordenador publica. Sem commit, sem push, sem mudar de branch.

## Por que
1. **Bug (meu):** `nexus-intelligence` calcula o host do projeto no começo de TODA ação; projetos sem `wordpress_url` e sem `domain` (Conquista Prime, Grupo RDM Assessoria) fazem `new URL('https://')` lançar → `500 operation_failed`. E a origem digitada pelo dono (`https://rdmadvogados.com.br/advogado-criminalista/`) é recusada por ter caminho (`allowed_origins_invalid`).
2. **Schema:** os blogs já servem JSON-LD de verdade (RDM: Rank Math emite LegalService `@id https://rdmadvogados.com.br/blog/#organization`; Direitos News: o tema `direitonews-rdm-v21` emite uma Organization `@id https://direitonews.rdmadvogados.com.br/blog/#organization` só com nome+url). Faltam dados na homepage (endereço, área atendida, perfis, parentOrganization). O auditor do plugin dá falso alarme porque só olha a metadado/opção do próprio plugin.
3. **Decisão de design:** NÃO preencher `_zica_posts_json_ld` em artigos antigos (duplicaria o schema do Rank Math). A homepage recebe um nó **com o MESMO `@id`** do que o site já serve, para enriquecer sem criar entidade nova.
