# RDM Advogados - pool visual oficial

Projeto WordPress: https://rdmadvogados.com.br/blog

Política:
- exatamente 3 imagens oficiais por módulo article, news e repost;
- geração sintética desativada;
- edição de fundo por artigo desativada, pois as três imagens já são finais;
- WebP, fonte 1200 px;
- hero alvo 1200x630 via WordPress;
- body 800 px;
- seleção automática com rotação;
- publicação sem imagem deve permanecer bloqueada quando a política exigir imagem;
- nenhuma imagem eleitoral ou genérica deve ser usada neste projeto.

Storage:
- bucket: rdm-brand-assets
- rdm-advogados/editorial/rdm-editorial-01.webp
- rdm-advogados/editorial/rdm-editorial-02.webp
- rdm-advogados/editorial/rdm-editorial-03.webp
