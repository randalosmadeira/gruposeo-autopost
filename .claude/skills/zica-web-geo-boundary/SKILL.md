# Fronteira Web/SEO/GEO

O repositório contém WordPress, portais, feeds, SEO/GEO e automações de publicação. Nesta fase, use esses arquivos apenas como contexto e contratos de integração.

## Bloqueio atual

Não usar navegador, cPanel, WordPress, deployment, DNS, CDN, Search Console ou publicação real. Não disparar webhooks de publicação nem testes contra portais reais.

## Quando houver autorização futura

Exigir staging, backup restaurável, dry-run, allowlist de destino, preflight, idempotência, auditoria, validação pós-ação e rollback. Separar fatos medidos de expectativas de SEO/GEO.
